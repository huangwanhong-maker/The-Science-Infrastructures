# navigation

*Status: planned. Bridge, height 3.* Finding one's place and way on the Earth, by the sky, by reckoning and by charts.

## 1. Scope

| Module | Scope |
|---|---|
| `celestial` | Celestial navigation and sight reduction |
| `dead_reckoning` | Dead reckoning |
| `charts` | Charts and routes: great circles and rhumb lines |
| later | GNSS |

The sight-reduction trainer and the route planner (planned applications).
