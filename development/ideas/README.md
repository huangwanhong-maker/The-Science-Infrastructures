# ideas: Seeds

## 1. Purpose

This is the cheapest place to write a thought that concerns more than one laboratory. An idea here may be wrong, and that is acceptable. An idea about one laboratory goes in that laboratory's own `development/ideas/`.

## 2. Convention

- **One file per idea.** Name it `YYYY-MM-DD-slug.md`, and give it the front matter `status: seed`.
- **Promoting an idea.** Move its substance into a laboratory, a library, a bridge or a decision. Set the idea's status to `promoted`, and add a link to where the substance went.
- **Abandoning an idea.** Never delete it. Set its status to `abandoned`, and add one sentence saying why.
