# Decision Log

Each record captures one decision that shapes the structure, conventions or tooling of the infrastructure as a whole.

- Records are numbered and are never rewritten.
- To change a decision, write a new record that supersedes or amends the old one, and update the old record's status to point to the new one.

Decisions that concern only one laboratory or one library are recorded in that repository's own `development/decisions/`. The first laboratory's are in [its log](https://github.com/huangwanhong-maker/Integrative_Astronomy_Geography_Oceanography_Laboratory/tree/main/development/decisions).
