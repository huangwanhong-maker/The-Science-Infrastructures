# applications/astronomy

These applications serve the field [`core/domains/astronomy`](../../core/domains/astronomy/).

| Application | Kind | Status | Content |
|---|---|---|---|
| [Celestial Atlas](celestial-atlas/) | tool | draft | The Sun, the Moon, the planets, the stars and galaxies, at any instant from 1849 to 2150 or live. Five views: Solar System, stellar neighbourhood (HYG or Gaia), galaxies and their relations, sky chart, orbits. |
| Orbital sandbox | lab | planned | Two-body and n-body motion, Kepler's laws, perturbations |
| Ephemeris calculator | tool | planned | Tables of positions in any time scale and reference frame |
