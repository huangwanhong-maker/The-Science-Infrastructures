# notebooks: Exploration and Teaching

*Status: planned.* Knowledge.

## 1. Purpose

This directory holds Jupyter notebooks for exploring ideas and for teaching them. Notebooks call the core through its Python bindings. Nothing depends on them.

## 2. Practice

- When code in a notebook proves useful, move it into a module and import it from there.
- Name teaching notebooks by subject. Prefix exploratory notebooks with the date, in the form `YYYY-MM-DD-slug.ipynb`.
- Clear large outputs before committing.
